# Análise de Corrosão — releases

Instaladores e atualizações do **Análise de Corrosão**, app de desktop da plataforma SimPipe Cloud.

Este repositório não tem código. Ele guarda só os instaladores publicados como *releases*, que
é de onde os apps instalados buscam as versões novas.

## ⚠️ Não renomear, não transferir, não apagar

O nome deste repositório está gravado em **todo app instalado**, e não há como mudá-lo depois.
Renomear, transferir ou apagar o repositório faz os apps pararem de receber atualizações — e
libera o nome para outra pessoa registrar.

Os releases são publicados por quem tem o certificado de assinatura da SimPipe Engenharia. O
app instalado recusa qualquer atualização que não venha assinada por ele.

## Instalar

Baixe o `SimPipe-corrosao-<versão>-setup.exe` do release mais recente. Depois de instalado, o app
se atualiza sozinho.

O app exige conta na plataforma SimPipe Cloud.
